# telomer-releases

Fertige, signierte und notarisierte Builds von **Telomer** — der Safari-Erweiterung,
mit der HELFERLINE Bewerber aus Fountain als Helferlein in Helix anlegt.

Hier liegen **nur die Bauergebnisse**, kein Quellcode:

- `latest.json` — das Manifest, das die App beim Suchen nach Updates liest
- Releases (`v2.1.0`, …) — das jeweilige `Telomer-<Version>.zip`

Das Repo ist öffentlich, damit die App ohne Zugangstoken nach Updates sehen kann.
Geheimnisse stecken keine darin: Anmeldedaten gibt jede:r selbst im Popup ein.

Installation und Ersteinrichtung stehen in der Anleitung, die dem Build beiliegt.
